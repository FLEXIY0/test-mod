# Indev++ — правила проекта

Сборка называется **Indev++** (бывш. InDev+). Это кастомный форк Minecraft
Indev в виде инстанса PrismLauncher.

## Обязательное правило

**После любого изменения инстанса (jar, ресурсы, конфиги, языки) всегда
пересобирай импортируемый в PrismLauncher архив `InDev++.zip` в корне
репозитория.** `dev/build.sh` делает это автоматически — заканчивай любую
задачу его запуском. Новая версия = новый `InDev++.zip` в том же коммите.

## Структура

- `InDev++.zip` — готовый к импорту в PrismLauncher архив (корень = содержимое
  инстанса: instance.cfg, mmc-pack.json, libraries/, minecraft/, patches/).
- `InDevPlus/` — распакованный инстанс (источник правды для zip).
  - `libraries/customjar-1.jar` — деобфусцированный игровой jar.
  - `minecraft/lang/` — языковые файлы (переопределяют встроенные в jar).
- `dev/` — нативная разработка: `reference-src/` (852 декомпилированных файла,
  95% компилируются), `src/` (активные правки), `build.sh` (правка → jar → zip).
- `tools/deobf/` — ремаппер/деобфускация (Remap.java, mappings.csv).
- `tools/russian-lang/` — байткод-подход (нужен только для 43 файлов из
  списка ограничений в dev/README.md) и исходник Lang.java.

## Как править код

Смотри `dev/README.md`. Кратко: скопируй файл из `dev/reference-src/` в
`dev/src/` (с путём пакета), отредактируй, запусти `./dev/build.sh`.

## Что нельзя ломать

- Имя класса `net.minecraft.client.d` — его вызывает PrismLauncher (mainClass
  из меты inf-20100618), как и `net.minecraft.client.MinecraftApplet`.
- Имя файла настроек `options_indev+.txt` — иначе у игрока сбросятся опции.
- Ключи `.lang`-файлов — это английские строки-оригиналы из кода.

## Проверка изменений jar

Запустить игру здесь нельзя (нет дисплея/нативов LWJGL) — минимум:
`tools/deobf/VerifyAll` (все классы через верификатор JVM) и
`tools/russian-lang/patch/FuncTest` (языковая система). Финальная проверка
GUI — запуск у пользователя.
