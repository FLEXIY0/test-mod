# Indev+ — переключаемые языки (UTF-8) + удаление брендинга Legacy+

Патч к кастомному jar форка **Indev+** (`InDevPlus/libraries/customjar-1.jar`),
добавляющий:

1. **Кнопку «Language»** в главном меню (внизу слева) — переключает язык по кругу.
2. **Загрузку своих языков** из папки `lang/` рядом с игрой (плюс встроенные
   `en_US` и `ru_RU` внутри jar). Выбор сохраняется в `lang/selected.txt`.
3. **Удаление упоминаний «The Legacy+ Team / Legacy+ project»** из интерфейса и
   консоли.

Кириллица уже поддерживается шрифтом (глифы в атласе + `font.txt` в UTF-8), так
что переводы отображаются корректно, а в книге с пером можно писать по-русски.

## Почему патч на уровне байткода, а не правка исходников

jar обфусцирован так, что **имя класса совпадает с именем соседнего пакета**
(например, класс `c` и пакет `c` в одном пакете). Для JVM это допустимо, но для
`javac` — нет: любая попытка перекомпилировать исходник падает с
`package ... clashes with class of same name`. Полная деобфускация кастомного
форка (без опубликованных маппингов) — отдельная большая работа. Поэтому
изменения вносятся напрямую в байткод, где конфликт имён значения не имеет:

- **`patch/StringPatch.java`** (ASM) — заменяет строковые константы Legacy+ во
  всех классах.
- **`patch/StructPatch.java`** (Javassist):
  - в шрифтовом рендерере (класс `net.minecraft.client.c.j`) оборачивает все
    6 публичных методов отрисовки/измерения строк вызовом `Lang.tr(...)` —
    **единая точка**, через которую локализуется весь интерфейс, без правки
    сотен классов;
  - в главном меню (`net.minecraft.client.c.at`) добавляет кнопку языка и
    обработчик, вызывающий `Lang.cycle()`.
- **`src/net/minecraft/client/Lang.java`** — рантайм-слой перевода: читает
  `lang/<код>.lang` (UTF-8, строки вида `English text=Перевод`), встроенные из
  jar + пользовательские из папки игры (папка имеет приоритет).

## Как локализуются строки

Весь текст UI проходит через шрифтовой рендерер, поэтому один хук в нём
переводит **статичные** надписи целиком (кнопки меню, надписи книги и т.п.).
Если ключа в словаре нет — строка отдаётся как есть (пользовательский ввод,
имена игроков, чат не трогаются). **Ограничение:** динамически собранные строки
(`"Page 1 of 3"`, `"by <ник>"`, склеенные подписи опций) не переводятся.

## Свой язык

1. Скопируйте `InDevPlus/minecraft/lang/template.lang.txt` как `<код>.lang`
   (напр. `uk_UA.lang`) в `minecraft/lang/`.
2. Переведите значения (`Английский=Перевод`).
3. В игре нажимайте «Language», пока не выберется ваш язык.

## Пересборка

```bash
./build.sh <исходный-customjar.jar> <результат.jar>
```

`<исходный>` — jar **без уже применённого** этого патча (повторный прогон добавил
бы вторую кнопку). Скрипт скачивает LWJGL 2 / ASM / Javassist в `libs/`.

### Проверка

`patch/Verify.java` прогоняет пропатченные классы через верификатор байткода
JVM; `patch/FuncTest.java` проверяет логику `Lang` (перевод, переключение,
удаление брендинга). Запуск игры для проверки GUI выполняется на машине
пользователя — в сборочном окружении нет дисплея/нативов LWJGL.
